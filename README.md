# Tarjeta de Presentación Digital 📇

¡Bienvenido a mi primer repositorio de desarrollo web! Este proyecto forma parte de mis primeros pasos aprendiendo la estructura y el diseño de páginas web.

## Tecnologías utilizadas
*   **HTML5:** Para la estructura y el esqueleto de la tarjeta.
*   **CSS3:** Para los estilos, colores, sombras y diseño visual.
*   *Próximamente:* **JavaScript** para añadir interactividad y comportamiento dinámico.
